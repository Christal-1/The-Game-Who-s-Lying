# 🔎 WHO'S LYING? — Version 1

A browser-based detective game built with **HTML, CSS and JavaScript**.

Step into the investigation, examine the evidence, question the suspects and work out **who's lying** before time runs out.

## 🎮 Play the Game

Open `index.html` in **Chrome, Edge or another modern web browser**.

### Your Mission

A company laptop has disappeared from a locked office.

Investigate the crime scene, examine the available evidence, identify contradictions and decide which suspect is responsible.

You have limited time and a limited number of accusations — so choose carefully.

## 🕵️ How to Play

1. Start the investigation.
2. Explore the four objects at the crime scene.
3. Investigate each object to discover evidence.
4. Review the evidence log.
5. Select the suspect you believe is lying.
6. Use a hint if you get stuck.
7. Make your accusation before time runs out.
8. Solve the case and see your final score.

## 📋 Case #01 — The Missing Laptop

**Location:** Marketing Office
**Difficulty:** Easy
**Suspects:** 4
**Clues:** 4
**Time Limit:** 2 minutes
**Attempts:** 3

### Suspects

* 👩🏽 Sarah — Marketing Manager
* 👨🏽 Mike — IT Support
* 👩🏾 Jessica — Sales Executive
* 👨🏾 Daniel — Office Assistant

Not every suspicious detail means someone is guilty. Pay attention to the **timeline, access records and evidence** before making your decision.

## 🎯 Game Rules

* Start with **1,000 points**
* Each discovered clue adds **100 points**
* Using a hint costs **150 points**
* A wrong accusation costs **200 points**
* A wrong accusation also uses **1 attempt**
* You have **3 attempts**
* You have **2 minutes** to solve the case
* Your remaining time can contribute to your final score
* The current case has a defined solution based on the evidence you discover

## 🔎 Evidence

The first version contains four investigation points:

* 🖥️ **Computer Activity**
* 📹 **CCTV Footage**
* 🚪 **Door Access Log**
* 🗂️ **Desk Note**

Carefully connecting the evidence is the key to solving the case.

## 💡 Hints

If you get stuck, you can use the hint system to receive a clue about where to focus your investigation.

Hints are optional, but they reduce your score.

## 🏆 Goal

Solve the case while:

* Finding as much evidence as possible
* Avoiding unnecessary accusations
* Using as few hints as possible
* Preserving as much time as possible
* Achieving the highest score you can
