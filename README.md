# 🔎 WHO'S LYING? — Version 1

A small browser detective game built with plain HTML, CSS and JavaScript.

## Play
Open `index.html` in Chrome, Edge or another modern browser.

Investigate the four objects, collect evidence, choose a suspect and make your accusation before time runs out.

## Rules
- Start with 1,000 points.
- Each clue adds 100 points.
- Hint costs 150 points.
- Wrong accusation costs 200 points and one attempt.
- Three attempts are available.
- Correct answer: Jessica.

## Files
- `index.html` — game structure
- `style.css` — visual design
- `game.js` — game logic

No installation or backend is required. The project is suitable for GitHub Pages.
